# Karahanlı RTS

> **Bu proje, Karahanlı RTS (Gerçek Zamanlı Strateji) oyunu için Phaser 3 ve TypeScript kullanılarak oluşturulmuş temel altyapıdır.**

## Teknolojiler
- **Oyun Motoru:** Phaser 3
- **Dil:** TypeScript
- **Geliştirme Sunucusu & Derleyici:** Vite

## Kurulum ve Çalıştırma

```bash
npm install
npm run dev
```

## Diğer Komutlar
- `npm run typecheck` — TypeScript tip kontrolü
- `npm run build` — Üretim (production) derlemesi oluşturur (`dist/`)
- `npm run preview` — Derlenen projeyi önizler
